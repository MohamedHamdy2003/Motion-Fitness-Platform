# الـEndpoints الجديدة | 22 نوفمبر 2026

المسارات الخمسة تخص المياه والخطوات والأهداف اليومية. كلها تحتاج `Authorization: Bearer <accessToken>` لحساب بريده متحقق. الأمثلة موجودة في مجلد **Activity** في Bruno.

| Method | Route                           | بتعمل إيه                                          | الطلب                                                                                   | حالة النجاح |
| ------ | ------------------------------- | -------------------------------------------------- | --------------------------------------------------------------------------------------- | ----------- |
| GET    | `/api/v1/me/activity/daily`     | تعرض إجمالي المياه والخطوات والأهداف وحالة الإكمال | `?date=2026-11-22` اختياري                                                              | `200`       |
| POST   | `/api/v1/me/activity/water`     | تسجل كمية مياه لليوم المحلي                        | `{"milliliters":250}` أو `{}` لإضافة 250 مل                                             | `201`       |
| DELETE | `/api/v1/me/activity/water/:id` | تحذف تسجيل مياه بالـID الخاص به                    | معرّف السجل في المسار                                                                   | `200`       |
| PUT    | `/api/v1/me/activity/steps`     | تسجل عدد الخطوات أو علامة الإكمال اليدوي           | `{"steps":6240,"manuallyCompleted":false}`، ويكفي إرسال أحد الحقلين. ويمكن إرسال `date` | `200`       |
| PUT    | `/api/v1/me/activity/goals`     | تغيّر أهداف المياه والخطوات                        | الحقلان مطلوبان، وإرسال `null` لأي هدف يعيده لقيمته الافتراضية                          | `200`       |

التاريخ بصيغة `YYYY-MM-DD`. عند غيابه يُستخدم اليوم حسب المنطقة الزمنية في ملف المستخدم. الطلب بتاريخ مستقبلي يرجع `422 ACTIVITY_DATE_IN_FUTURE`. قراءة يوم سابق تعرض أهداف الحساب الحالية. الخطوات تقبل عددًا صحيحًا من 0 إلى 200000، وكل POST للمياه يضيف سجلًا مستقلًا من 1 إلى 2000 مل. أهداف المياه بين 250 و10000 مل، والخطوات بين 100 و100000.

## أمثلة للردود

**GET /me/activity/daily**

```json
{
  "date": "2026-11-22",
  "water": {
    "totalMl": 250,
    "logCount": 1,
    "goalMl": 2500,
    "goalReached": false,
    "recentLogs": [
      {
        "id": "61fc6865-2499-4745-a814-54caea59d724",
        "milliliters": 250,
        "createdAt": "2026-11-22T08:00:00.000Z"
      }
    ]
  },
  "steps": {
    "count": 6240,
    "goal": 10000,
    "manuallyCompleted": false,
    "goalReached": false
  }
}
```

`recentLogs` فيها آخر 50 تسجيل مياه على الأكثر، والإجمالي يشمل كل تسجيلات اليوم.

**POST /me/activity/water**

```json
{
  "id": "61fc6865-2499-4745-a814-54caea59d724",
  "date": "2026-11-22",
  "milliliters": 250,
  "createdAt": "2026-11-22T08:00:00.000Z"
}
```

**DELETE /me/activity/water/:id**

```json
{ "id": "61fc6865-2499-4745-a814-54caea59d724" }
```

السجل غير الموجود أو المملوك لحساب آخر يرجع `404 NOT_FOUND`.

**PUT /me/activity/steps**

```json
{
  "date": "2026-11-22",
  "count": 6240,
  "goal": 10000,
  "manuallyCompleted": false,
  "goalReached": false
}
```

تُحسب `goalReached` من عدد الخطوات أو الإكمال اليدوي. الحقل الذي لا ترسله يحتفظ بقيمته إذا سُجّل اليوم من قبل.

**PUT /me/activity/goals**

إرسال `{"waterGoalMl":null,"stepsGoal":null}` يرجع الأهداف الافتراضية.

```json
{ "waterGoalMl": 2500, "stepsGoal": 10000 }
```
