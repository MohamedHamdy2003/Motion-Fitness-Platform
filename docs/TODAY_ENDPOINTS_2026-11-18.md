# الـEndpoints الجديدة — 18 نوفمبر 2026

كل الطلبات تحتاج Bearer token، وواجهات admin تحتاج دور ADMIN.

| Method / Endpoint                                 | الوظيفة                                             | Body                                                                                       | Response مختصر                                                                                                                                                                                                                      |
| ------------------------------------------------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| POST /api/v1/me/matching/retry                    | يبدأ الاختيار أو يعيد طلبًا فاشلًا للبيانات الحالية | {}                                                                                         | {runId,status,selectedProgramVersionId,reasonCodes,failureCode,assignmentStatus:"NOT_ASSIGNED",nextFeature:"F06",createdAt}؛ البيانات الناقصة أو الإعدادات غير المكتملة أو تجاوز حد التشغيل (RATE_LIMITED) ترجع {status,runId:null} |
| POST /api/v1/admin/matching/rulesets              | إنشاء مسودة تعليمات للموديل                         | {instructionVersion,instructions,model}                                                    | {id,status:"DRAFT",active:false,instruction_version,instructions,model,policy_version,schema_version,evaluation_reference:null,created_at,published_at:null}                                                                        |
| GET /api/v1/admin/matching/rulesets               | قائمة إعدادات الاختيار                              | بدون Body؛ limit/offset اختياريان                                                          | {items:[ruleset],limit,offset}                                                                                                                                                                                                      |
| POST /api/v1/admin/matching/rulesets/:id/simulate | تجربة القواعد على بيانات اصطناعية                   | {primaryGoal,fitnessLevel,trainingDaysPerWeek,age,heightCm,weightKg,targetWeightKg,gender} | {runId,status,selectedProgramVersionId,reasonCodes,failureCode,assignmentStatus:"NOT_ASSIGNED",nextFeature:"F06",createdAt}                                                                                                         |
| POST /api/v1/admin/matching/rulesets/:id/publish  | اعتماد قواعد بعد مراجعة الجودة وتفعيلها             | {qualityApproved:true,evaluationReference}                                                 | ruleset بحالة PUBLISHED وactive:true                                                                                                                                                                                                |
| GET /api/v1/admin/matching/runs/:id               | متابعة تشغيل أو محاكاة للأدمن                       | بدون Body                                                                                  | {id,user_id,ruleset_id,kind,status,input_hash,profile_snapshot,metrics_snapshot,candidates,decision,failure_code,attempts,duration_ms,...}                                                                                          |

POST يرجع 201؛ GET يرجع 200. القيم الممكنة للقوائم تُقرأ من lookups الحالية. حد تدريب 2 إلى 5 أيام. model يطابق AI_MODEL الموجود في خدمة Mastra.
